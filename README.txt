VELOURA — Website High Heels

CARA MENJALANKAN
1. Ekstrak file ZIP.
2. Buka index.html di browser (Chrome/Edge).
3. Website menggunakan Google Fonts dan foto dari Unsplash, jadi koneksi internet diperlukan untuk memuat font/foto.

SEBELUM MENERIMA PESANAN
1. Buka script.js.
2. Cari baris: const WHATSAPP_NUMBER = "6281234567890";
3. Ganti nomor contoh itu dengan nomor WhatsApp bisnis kamu, format internasional tanpa tanda +.
   Contoh nomor Indonesia: 62812xxxxxxxx (jangan gunakan awalan 0).
4. Edit nama produk, harga, deskripsi, dan URL foto pada array `products` di script.js.
5. Edit teks brand dan About di index.html jika diperlukan.

CATATAN
- VELOURA adalah nama brand usulan, pastikan cek ketersediaan nama/merek sebelum digunakan secara komersial.
- Harga dan foto adalah contoh/demo, silakan ganti sesuai produk asli.
- Form pemesanan menyusun detail order lalu membuka WhatsApp; belum terhubung ke payment gateway, database, atau stok otomatis.
- Website ini statis dan bisa di-host di layanan seperti GitHub Pages, Netlify, atau hosting pilihanmu.
